# CLI specification · todo-cli

> IDs SPEC-C-xx. Command-line interface contract + terminal output (the product has no GUI, so the interface and UI specs are merged).

## Common conventions
- Command name: `todo`
- Parsing: Python standard-library `argparse` with sub-commands.
- Exit codes: success `0`; user error (empty text / unknown id) `1`; runtime error such as a corrupt data file `2`.
- Normal output goes to stdout; error messages go to stderr.

## Command list
| ID | Command | Purpose | Function |
|----|---------|---------|----------|
| SPEC-C-01 | `todo add <text>` | Add a task | SPEC-F-01 |
| SPEC-C-02 | `todo list` | View the list | SPEC-F-02 |
| SPEC-C-03 | `todo done <id>` | Mark as done | SPEC-F-03 |
| SPEC-C-04 | `todo delete <id>` | Delete a task | SPEC-F-04 |

## Detailed contracts

### SPEC-C-01 add
- Usage: `todo add "Buy milk"`
- Argument: `text` (positional, required; quote it if it contains spaces)
- Success output: `Added #<id>: <text>`, exit code 0
- Error: text empty after stripping → stderr `Error: task text must not be empty`, exit code 1

### SPEC-C-02 list
- Usage: `todo list`
- Success output (non-empty, ascending id): one line per task, `#<id> <status> <text>`
  - Example:
    ```
    #1 [ ] Buy milk
    #2 [x] Pay rent
    ```
- Empty list: `The list is empty. Add a task with: todo add`, exit code 0

### SPEC-C-03 done
- Usage: `todo done 1`
- Argument: `id` (positional, integer)
- Success output: `Completed #<id>`, exit code 0
- Error: unknown id → stderr `Error: task #<id> does not exist`, exit code 1
- Marking a done task again: still prints `Completed #<id>`, exit code 0 (idempotent, no error)

### SPEC-C-04 delete
- Usage: `todo delete 1`
- Argument: `id` (positional, integer)
- Success output: `Deleted #<id>`, exit code 0
- Error: unknown id → stderr `Error: task #<id> does not exist`, exit code 1

## Output format conventions (SPEC-C-06, the UI part)
- Status markers: open `[ ]`, done `[x]`.
- Id prefix `#`.
- Error prefix `Error: `, always on stderr.
- Never print a raw traceback (NFR-001).

## No arguments / help (SPEC-C-07)
- `todo` or `todo -h`: show the usage summary (generated by argparse, with a one-line description on top).
