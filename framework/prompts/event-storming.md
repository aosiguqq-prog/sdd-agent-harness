# Prompt: event storming

Goal: sketch the domain quickly and produce the skeleton of `discovery.md`.

## Instruction
Work through the following in order (in business language, no technical terms):
1. **Domain events** (past tense): what happens in the system, e.g. "order submitted".
2. **Commands**: the action / intent that causes each event, e.g. "submit order".
3. **Actors**: who issues each command.
4. **External systems**: third-party or external services depended on.
5. **Read models / screens**: what the user needs to see to make decisions.
6. **Boundaries**: cluster the events and draw the in / out-of-scope line.
7. **Glossary**: define the key nouns that come up along the way.

## Output
Fill the matching sections of `templates/00-discovery.md`; contradictions and gaps go into "open questions".
