# Prompt: TDD · GREEN (minimal implementation)

## Instruction
You are the implementer. Read the failing test and the hand-off note:
1. Write the minimal implementation that **just makes the test pass**.
2. Run the full suite and confirm everything is green and nothing else broke.

## Constraints
- Implement nothing the tests do not require (YAGNI).
- Never change a test to fit the implementation (unless the test is genuinely wrong — then state why explicitly).
- No unrelated refactoring.

## Output
Implementation in `src/` + a hand-off note (what was implemented, which shortcuts await refactoring). Hand over to the refactorer.
